# We Split

Веб-приложение для разделения общих расходов в компании. Участники мероприятия добавляют свои траты, а приложение считает, кто кому сколько должен.

**Стек:** React, FastAPI, PostgreSQL.

## Идея проекта

Например, компания собралась отдохнуть:

- кто-то закупил еду;
- кто-то купил выпивку;
- кто-то заплатил за аренду места.

Каждый добавляет свою трату в мероприятие и указывает, как её разделить:

- **Пополам** — сумма делится поровну между участниками.
- **Вручную** — у каждого участника своя доля. Например, Пете купили 6 банок, и он должен 600, а Васе купили 4 банки, и он должен 400.

## Схема базы данных

```
+-----------------------+          +-----------------------+          +-----------------------+
|         events        | 1 ---< N |      events_users     | N >--- 1 |         users         |
+-----------------------+          +-----------------------+          +-----------------------+
| PK id         : int   |          | PK id         : int   |          | PK id         : int   |
|    name       : str   |          | FK event_id   : int   |          |    name       : str   |
|    date       : date  |          | FK user_id    : int   |          |    login      : str   |
| FK author_id  : int   |          +-----------------------+          +-----------------------+
+-----------------------+
            | 1                                                                   | 1
            |                                                                     |
            | N                                                                   | N
+-----------------------+                                             +-----------------------+
|        expenses       |  1 -------------------------------------< N |         debts         |
+-----------------------+                                             +-----------------------+
| PK id         : int   |                                             | PK id         : int   |
|    name       : str   |                                             |    name       : str   |
|    amount     : int   |                                             | FK debtor_id  : int   |
| FK payer_id   : int   |                                             | FK expense_id : int   |
| FK event_id   : int   |                                             |    amount     : int   |
+-----------------------+                                             |    is_settled : bool  |
                                                                      +-----------------------+
```

`PK` — первичный ключ, `FK` — внешний ключ. На диаграмме показаны не все связи с `users`, полный список ниже.

## Связи

| Связь | Тип | Через поле |
|---|---|---|
| `events` → `events_users` | один-ко-многим | `events_users.event_id` |
| `users` → `events_users` | один-ко-многим | `events_users.user_id` |
| `events` ↔ `users` | многие-ко-многим | через таблицу `events_users` |
| `users` → `events` | один-ко-многим | `events.author_id` |
| `events` → `expenses` | один-ко-многим | `expenses.event_id` |
| `users` → `expenses` | один-ко-многим | `expenses.payer_id` |
| `expenses` → `debts` | один-ко-многим | `debts.expense_id` |
| `users` → `debts` | один-ко-многим | `debts.debtor_id` |

Тип связи — это свойство не поля, а пары таблиц.
